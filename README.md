# pulsar-a/tap

Homebrew casks for pulsar-a's apps.

```bash
brew install pulsar-a/tap/uku
brew install pulsar-a/tap/yasa
```

| Cask | App |
|---|---|
| `uku` | [Uku](https://ukumd.com/), a quiet Markdown reader |
| `yasa` | [Yasa](https://yasatodo.com/), a Kanban todo app with your current task in the menu bar |
